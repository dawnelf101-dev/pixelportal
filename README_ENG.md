# Minecraft Bedrock Server Connector (PS5 / Xbox)

Connect your console directly to any external Bedrock server – without changing DNS settings or tweaking console configurations.

---

## ⚡ How It Works

1. **Enter Server IP + Port:** Save as many custom servers as you like (external IPs supported).
2. **Press "Start":** The app opens local port `19132` on your phone.
3. **Find in Game:** Your PS5/Xbox will discover the app under **Friends → LAN Games** in Minecraft.
4. **Connect:** The console connects to the phone, which responds with a *Transfer Packet* containing the destination IP.
5. **Direct Connection:** The console connects **DIRECTLY** to the target server.
6. **Done:** You can close the app afterwards — the server connection remains active.

> **Key Advantage:** No DNS changes required. No console settings to adjust. Uses local Wi-Fi only.

---

## ⚙️ Requirements

* **Same Network:** Android phone and PS5/Xbox must be connected to the same Wi-Fi.
* **Android Version:** Android 8.0 (API Level 26) or higher.
* **Minecraft Setting:** **"Visible to LAN Players"** must be turned `ON` in Minecraft settings.
